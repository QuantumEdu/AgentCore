# Prompt Structures

## 1. Code Analysis and Understanding

### Goal
Analyze and understand the codebase structure, patterns and relationships without modifying code.

### Approach
1. Understand the scope.
2. Read the relevant files.
3. Trace architecture, dependencies and data flow.
4. Document strengths, concerns and opportunities.

### Guidelines
- Read before inferring.
- Prefer evidence over assumptions.
- Focus on understanding first.
- Be concise but concrete.

### Output Format
1. Overview
2. Structure
3. Key Patterns
4. Data Flow
5. Observations
6. Recommendations

## 2. Documentation Generation

### Goal
Create clear, useful and action-oriented documentation for users or developers.

### Principles
- clarity first
- complete but concise
- actionable
- example-driven

### Structure
1. Title
2. Summary
3. Prerequisites
4. Steps
5. Examples
6. Notes
7. See Also

## 3. Code Refactoring

### Goal
Improve maintainability, clarity and safety while preserving behavior.

### Flow
1. Understand current behavior.
2. Identify issues.
3. Plan small safe changes.
4. Verify.
5. Update documentation if needed.

### Safety Checklist
- tests pass
- behavior preserved
- complexity reduced
- naming improved
- no security regressions
- no documentation drift
