# Prompt Improver

## Decisión

Para mejorar prompts es mejor una **skill** que un agente.

## Por qué skill y no agente

### Skill
- respuesta rápida
- reusable
- portable
- menos tokens
- ideal para transformar, refinar y estandarizar prompts

### Agente
- útil solo si hubiera que entrevistar al usuario mucho, comparar variantes o diseñar una librería completa de prompts
- exceso para mejoras normales

## Estructura estándar

Reescribir prompts con esta forma:

1. **Title**
2. **Goal**
3. **Scope / assumptions**
4. **Approach**
5. **Constraints / guidelines**
6. **Output format**
7. **Quality checks**

## Modos recomendados

- **compacto**: breve y ejecutable
- **profesional**: bien estructurado y claro
- **exigente**: agrega checklist y criterios de calidad

## Plantillas base

Este skill debe usar como referencia ejemplos como:

- análisis de código
- documentación
- refactoring

y producir una versión mejorada, consistente y lista para reutilizar.
