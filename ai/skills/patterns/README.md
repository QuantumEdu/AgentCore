# Patterns Reference

Este directorio contiene **material de referencia**, no skills operativas.

## Qué hay aquí

- `hexagonal.md`
- `solid.md`
- `design-patterns.md`
- `testing-patterns.md`

## Cómo usarlo

Usa estos archivos cuando necesites:

- ejemplos de implementación
- criterios de diseño
- apoyo para review o decisiones de arquitectura
- vocabulario compartido sobre patrones

## Regla importante

No cargues este directorio entero por defecto en tareas pequeñas.
Consulta solo el patrón relevante cuando realmente aporte valor.

## Relación con las skills

- Las skills operativas viven en `/ai/skills/*/SKILL.md`.
- Estos archivos complementan skills como `coding-conventions`, `add-endpoint` o `change-review`, pero no las reemplazan.
