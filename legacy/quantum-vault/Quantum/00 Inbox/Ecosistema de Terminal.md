# Ecosistema de Terminal

Listado de herramientas que conforman el entorno de terminal actual.

---

| Herramienta | Descripción |
|-------------|-------------|
| **Neovim** (`nvim`) | Editor de texto principal |
| **LazyVim** | Framework/configuración de Neovim |
| **Tmux** | Multiplexor de terminal y gestor de sesiones |
| **Fish** | Shell interactiva por defecto — rápida y con autocompletado |
| **Zoxide** (`z`) | Navegador de directorios inteligente — reemplazo de `cd` |
| **Lazygit** | Interfaz gráfica de terminal para Git |
| **Lazydocker** | Interfaz gráfica de terminal para Docker |
| **Btop** | Monitor avanzado de recursos del sistema |
| **Fzf** | Buscador difuso en línea de comandos |
| **Ripgrep** (`rg`) | Buscador de texto ultrarrápido — reemplazo de `grep` |
| **Fd** | Alternativa moderna y rápida a `find` |
| **Bat** | Clon de `cat` con resaltado de sintaxis |
| **Eza** | Reemplazo moderno y colorido para `ls` |
| **Starship** | Prompt personalizable y rápido para la shell |
| **Zsh** | Shell alternativa instalada (disponible si decides cambiar desde Fish) |
| **GitHub CLI** (`gh`) | Herramienta oficial de línea de comandos de GitHub |
