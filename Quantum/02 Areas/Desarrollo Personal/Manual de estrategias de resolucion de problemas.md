## <a name="los-5-porques"></a>1. Los 5 Porqués

### Descripción
Técnica iterativa de preguntas utilizada para explorar las relaciones causa-efecto que generan un problema particular.

### Pasos a Seguir
1. Identificar el problema específico
2. Preguntar "¿Por qué?" ocurre este problema
3. Para cada respuesta, preguntar "¿Por qué?" nuevamente
4. Repetir el proceso cinco veces o hasta encontrar la causa raíz
5. Identificar contramedidas para prevenir la recurrencia

### Ejemplo Práctico
**Problema**: Alto índice de devoluciones de un producto electrónico

1. ¿Por qué hay tantas devoluciones?
   - Porque los clientes reportan que el producto no funciona correctamente
2. ¿Por qué no funciona correctamente?
   - Porque la batería se agota muy rápido
3. ¿Por qué se agota la batería rápido?
   - Porque el firmware tiene un bug que impide el modo de ahorro de energía
4. ¿Por qué existe este bug?
   - Porque no se realizaron pruebas suficientes antes del lanzamiento
5. ¿Por qué no se realizaron suficientes pruebas?
   - Porque el calendario de lanzamiento era muy ajustado

**Solución**: Implementar un proceso de QA más riguroso y ajustar los tiempos de desarrollo.

## <a name="lluvia-de-ideas"></a>2. Lluvia de Ideas (Brainstorming)

### Descripción
Técnica grupal para generar ideas creativas y soluciones innovadoras a problemas.

### Pasos a Seguir
1. Definir el problema o tema claramente
2. Establecer reglas básicas:
   - No criticar ideas
   - Fomentar ideas poco convencionales
   - Construir sobre las ideas de otros
   - Cantidad sobre calidad inicial
3. Generar ideas
4. Registrar todas las ideas
5. Evaluar y seleccionar las mejores ideas

### Ejemplo Práctico
**Problema**: ¿Cómo reducir el consumo de papel en la oficina?

**Ideas generadas**:
- Implementar un sistema de firmas digitales
- Crear una política de "cero impresiones" para reuniones
- Instalar tabletas en salas de conferencias
- Gamificar la reducción de impresiones por departamento
- Configurar impresoras para doble cara por defecto
- Crear un sistema de cuotas de impresión
- Digitalizar todo el archivo histórico
- Implementar un sistema de gestión documental

## <a name="scamper"></a>3. SCAMPER

### Descripción
Técnica que utiliza un conjunto de preguntas dirigidas para evolucionar ideas existentes.

### Pasos a Seguir
S - Sustituir
C - Combinar
A - Adaptar
M - Modificar
P - Proponer otros usos
E - Eliminar
R - Reordenar

### Ejemplo Práctico
**Producto**: Servicio de entrega de comida a domicilio

**Aplicación de SCAMPER**:
- Sustituir: Repartidores por drones
- Combinar: Servicio de comida con clases de cocina virtuales
- Adaptar: Sistema para personas con dietas específicas
- Modificar: Agregar seguimiento en tiempo real
- Proponer: Uso del servicio para entregas de otros productos
- Eliminar: Eliminar tiempo de espera con IA predictiva
- Reordenar: Cambiar el proceso de pedido a automatizado

## <a name="seis-sombreros"></a>4. Los Seis Sombreros para Pensar

### Descripción
Método para analizar decisiones desde diferentes perspectivas, donde cada "sombrero" representa un estilo de pensamiento diferente.

### Pasos a Seguir
1. Asignar roles según el color del sombrero:
   - Blanco: Datos y hechos objetivos
   - Rojo: Intuición y emociones
   - Negro: Riesgos y problemas potenciales
   - Amarillo: Beneficios y optimismo
   - Verde: Creatividad y nuevas ideas
   - Azul: Proceso y control
2. Analizar la situación desde cada perspectiva
3. Documentar las observaciones
4. Sintetizar las conclusiones

### Ejemplo Práctico
**Decisión**: Implementar trabajo remoto permanente

**Análisis por Sombrero**:
- Blanco: 70% de empleados tienen equipo adecuado en casa
- Rojo: Empleados expresan preocupación por aislamiento
- Negro: Riesgos de seguridad informática, menor colaboración
- Amarillo: Reducción de costos, mayor productividad potencial
- Verde: Sistema híbrido con espacios de co-working
- Azul: Plan de implementación gradual en 6 meses

## <a name="pareto"></a>5. Análisis de Pareto

### Descripción
Método para identificar el 20% de las causas que producen el 80% de los efectos.

### Pasos a Seguir
1. Recolectar datos del problema
2. Ordenar los datos de mayor a menor frecuencia
3. Calcular porcentajes acumulados
4. Crear diagrama de Pareto
5. Analizar resultados
6. Priorizar acciones correctivas

### Ejemplo Práctico
**Problema**: Quejas de clientes en un hotel

**Análisis**:
- Tiempo de check-in (40%)
- Limpieza de habitaciones (25%)
- Ruido (15%)
- Calidad del desayuno (10%)
- Temperatura habitación (5%)
- Otros (5%)

**Solución**: Enfocarse en optimizar el proceso de check-in y mejorar los protocolos de limpieza.

## <a name="triz"></a>6. TRIZ

### Descripción
Metodología sistemática para resolver problemas técnicos y de innovación.

### Pasos a Seguir
1. Identificar el problema específico
2. Formular el problema ideal
3. Identificar la contradicción principal
4. Consultar los 40 principios inventivos
5. Aplicar principios relevantes
6. Desarrollar solución específica

### Ejemplo Práctico
**Problema**: Necesidad de aumentar la resistencia de un material sin aumentar su peso

**Aplicación TRIZ**:
1. Contradicción: Resistencia vs Peso
2. Principios aplicables:
   - Principio 1: Segmentación
   - Principio 40: Materiales compuestos
3. Solución: Desarrollar una estructura de panal con materiales compuestos

## <a name="listas-verificacion"></a>7. Listas de Verificación

### Descripción
Herramientas sistemáticas para asegurar la completitud y consistencia en procesos.

### Pasos a Seguir
1. Identificar el proceso a verificar
2. Listar todos los pasos críticos
3. Organizar en secuencia lógica
4. Incluir puntos de verificación
5. Establecer responsables
6. Documentar resultados

### Ejemplo Práctico
**Proceso**: Lanzamiento de nuevo producto

**Lista de Verificación**:
- [ ] Investigación de mercado completada
- [ ] Prototipo aprobado
- [ ] Pruebas de usuario realizadas
- [ ] Documentación técnica preparada
- [ ] Plan de marketing desarrollado
- [ ] Canales de distribución confirmados
- [ ] Soporte post-venta establecido

## <a name="abogado-diablo"></a>8. Abogado del Diablo

### Descripción
Técnica para identificar debilidades en planes o propuestas mediante cuestionamiento crítico.

### Pasos a Seguir
1. Presentar la propuesta inicial
2. Asignar rol de "abogado del diablo"
3. Cuestionar supuestos
4. Identificar riesgos potenciales
5. Proponer escenarios adversos
6. Refinar la propuesta

### Ejemplo Práctico
**Propuesta**: Nuevo sistema de reservas online

**Cuestionamiento**:
- ¿Qué pasa si el sistema se cae?
- ¿Cómo manejaremos clientes sin acceso a internet?
- ¿Qué sucede con las reservas existentes?
- ¿Cómo garantizamos la seguridad de los datos?
- ¿Qué hacemos si los empleados resisten el cambio?

## <a name="delphi"></a>9. Técnica Delphi

### Descripción
Método para obtener consenso de expertos mediante rondas iterativas de cuestionarios.

### Pasos a Seguir
1. Seleccionar panel de expertos
2. Preparar cuestionario inicial
3. Distribuir y recolectar respuestas
4. Analizar y sintetizar resultados
5. Compartir resultados anónimos
6. Repetir proceso hasta consenso

### Ejemplo Práctico
**Tema**: Predicción de tendencias tecnológicas

**Proceso**:
Ronda 1: Identificación de tendencias
Ronda 2: Evaluación de impacto
Ronda 3: Probabilidad de adopción
Ronda 4: Consenso final sobre prioridades

## <a name="tgn"></a>10. TGN (Técnica de Grupo Nominal)

### Descripción
Método estructurado para toma de decisiones grupales que combina trabajo individual y discusión.

### Pasos a Seguir
1. Presentar la pregunta/problema
2. Generación silenciosa de ideas
3. Registro rotativo de ideas
4. Discusión para clarificación
5. Votación y ranking
6. Discusión de resultados

### Ejemplo Práctico
**Problema**: Mejorar la satisfacción del empleado

**Proceso TGN**:
1. Ideas generadas individualmente
2. Compartir en ronda (una idea por persona)
3. Clarificar y combinar ideas similares
4. Votar top 5 ideas
5. Discutir resultados
6. Plan de implementación

## <a name="desviacion-positiva"></a>11. Desviación Positiva

### Descripción
Enfoque que identifica y amplifica soluciones exitosas que ya existen dentro del sistema.

### Pasos a Seguir
1. Definir el problema y resultados deseados
2. Identificar "desviadores positivos"
3. Estudiar sus comportamientos y estrategias
4. Diseñar intervenciones basadas en hallazgos
5. Monitorear y ajustar
6. Escalar soluciones exitosas

### Ejemplo Práctico
**Problema**: Alta rotación de personal en cadena de restaurantes

**Análisis**:
- Identificación de sucursales con menor rotación
- Estudio de prácticas de gestión
- Hallazgos: Programa de mentoring, horarios flexibles
- Implementación en otras sucursales
- Resultado: Reducción del 40% en rotación

## <a name="indagacion-apreciativa"></a>12. Indagación Apreciativa

### Descripción
Método que se centra en las fortalezas y éxitos pasados para construir soluciones futuras.

### Pasos a Seguir (Ciclo 4D)
1. Descubrir: Identificar lo mejor que existe
2. Soñar: Imaginar qué podría ser
3. Diseñar: Determinar qué debería ser
4. Destino: Crear lo que será

### Ejemplo Práctico
**Contexto**: Mejora de cultura organizacional

**Proceso**:
- Descubrir: Entrevistas sobre mejores experiencias laborales
- Soñar: Visión colectiva de cultura ideal
- Diseñar: Plan de acción basado en fortalezas
- Destino: Implementación de iniciativas específicas

## <a name="campo-fuerzas"></a>13. Análisis de Campo de Fuerzas

### Descripción
Técnica para evaluar fuerzas que favorecen o resisten un cambio propuesto.

### Pasos a Seguir
1. Describir el cambio deseado
2. Identificar fuerzas impulsoras
3. Identificar fuerzas restrictivas
4. Asignar puntuación a cada fuerza
5. Analizar el balance
6. Desarrollar estrategias

### Ejemplo Práctico
**Cambio**: Implementación de nuevo software

**Análisis**:
Fuerzas Impulsoras (+):
- Mejora eficiencia (+5)
- Reduce costos (+4)
- Competitividad (+3)

Fuerzas Restrictivas (-):
- Resistencia al cambio (-4)
- Costos de capacitación (-3)
- Tiempo de adaptación (-2)

## <a name="ssm"></a>14. Metodología de Sistemas Suaves (SSM)

### Descripción
Enfoque para abordar problemas complejos considerando factores humanos y culturales.

### Pasos a Seguir
1. Explorar situación problemática
2. Expresar situación mediante imágenes
3. Definir sistemas relevantes
4. Crear modelos conceptuales
5. Comparar modelos con realidad
6. Identificar cambios factibles
7. Implementar mejoras

### Ejemplo Práctico
**Problema**: Comunicación interdepartamental deficiente

**Aplicación SSM**:
1. Mapeo de interacciones actuales
2. Identificación de barreras culturales
3. Diseño de nuevo sistema de comunicación
4. Implementación gradual con feedback

## <a name="impacto-cruzado"></a>16. Análisis de Impacto Cruzado

### Descripción
Método para evaluar interrelaciones entre diferentes variables o eventos.

### Pasos a Seguir
1. Identificar variables clave
2. Crear matriz de impacto
3. Evaluar influencias mutuas
4. Calcular impactos indirectos
5. Identificar variables críticas
6. Desarrollar estrategias

### Ejemplo Práctico
**Análisis**: Factores de éxito en e-commerce

**Variables**:
- Velocidad sitio web
- Experiencia usuario
- Precio productos
- Servicio cliente
- Marketing digital

## <a name="pensamiento-analogico"></a>17. Pensamiento Analógico

### Descripción
Técnica que utiliza analogías para resolver problemas mediante comparaciones con situaciones similares.

### Pasos a Seguir
1. Definir problema central
2. Identificar campos análogos
3. Encontrar similitudes
4. Transferir soluciones
5. Adaptar al contexto
6. Implementar y evaluar

### Ejemplo Práctico
**Problema**: Gestión de tráfico urbano

**Analogía**: Sistema circulatorio
- Arterias principales = Avenidas
- Capilares = Calles locales
- Células = Vehículos
- Ritmo cardíaco = Semáforos

## <a name="backcasting"></a>18. Backcasting

### Descripción
Método que parte de un futuro deseado y planifica hacia atrás hasta el presente.

### Pasos a Seguir
1. Definir visión futura
2. Establecer marco temporal
3. Identificar hitos clave
4. Planificar pasos intermedios
5. Identificar recursos necesarios
6. Desarrollar plan de acción

### Ejemplo Práctico
**Objetivo**: Carbono neutral en 2030

**Plan retrospectivo**:
2030: 100% energía renovable
2028: 80% flota eléctrica
2026: Infraestructura de carga
2024: Políticas de reducción
2023: Auditoría inicial

## <a name="pensamiento-lateral"></a>19. Pensamiento Lateral

### Descripción
Enfoque que busca soluciones no convencionales mediante perspectivas alternativas.

### Pasos a Seguir
1. Cuestionar supuestos
2. Buscar alternativas
3. Generar provocaciones
4. Explorar ideas ilógicas
5. Encontrar nuevas conexiones
6. Desarrollar soluciones

### Ejemplo Práctico
**Problema**: Congestión en supermercado

**Solución lateral**:
- Estantes móviles que van al cliente
- Sistema de compra inverso
- Horarios personalizados por perfil

## <a name="pensamiento-contrafactual"></a>20. Pensamiento Contrafactual

### Descripción
Técnica que explora escenarios alternativos para mejorar la toma de decisiones.

### Pasos a Seguir
1. Identificar decisión/evento clave
2. Generar escenarios alternativos
3. Analizar consecuencias
4. Identificar factores críticos
5. Desarrollar estrategias preventivas
6. Implementar aprendizajes

### Ejemplo Práctico
**Situación**: Lanzamiento fallido de producto

**Análisis contrafactual**:
- "Si hubiéramos hecho más pruebas..."
- "Si el precio hubiera sido menor..."
- "Si el marketing hubiera sido diferente..."
- Aprendizajes para futuros lanzamientos
