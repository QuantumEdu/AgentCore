### 1. ¿Qué es Markdown?

**Breve introducción:** Markdown es un lenguaje de marcado ligero que permite formatear texto sin necesidad de código complejo. Fue creado para que el texto sea fácil de leer en formato plano y fácil de convertir en HTML para su publicación en la web.

**¿Por qué es útil aprender Markdown?** Markdown es ampliamente usado en plataformas como GitHub, foros, blogs y documentación técnica porque facilita el formateo de texto de forma rápida y sencilla. También ayuda a escribir documentos con formato sin preocuparte por el diseño, ya que puedes concentrarte en el contenido.

**Principales aplicaciones y dónde se utiliza:**

- Documentación técnica en GitHub.
- Redacción de artículos y blogs en plataformas como Medium o Dev.to.
- Notas y documentos personales en aplicaciones como Notion.

### 2. Sintaxis Básica para Formateo de Texto

**Encabezados (Títulos de diferentes niveles):**

- Los encabezados se crean con el símbolo `#`.
- Cuantos más `#` uses, menor será el nivel del encabezado (de 1 a 6).

**Ejemplos:**

markdown

Copiar código

`# Encabezado 1 ## Encabezado 2 ### Encabezado 3`

**Estilos de texto:**

- **Negrita**: usa dos asteriscos (`**texto**`) o guiones bajos dobles (`__texto__`).
- _Cursiva_: usa un asterisco (`*texto*`) o un guion bajo (`_texto_`).
- ~~Tachado~~: usa dos virgulillas (`~~texto~~`).

**Ejemplo:**

markdown

Copiar código

`Este es un texto **en negrita** y este es *en cursiva*. También puedes combinar estilos como **_negrita y cursiva_**.`

### 3. Listas en Markdown

**Listas no ordenadas:**

- Usa `-`, `*` o `+` para listas con viñetas.

markdown

Copiar código

`- Primer ítem - Segundo ítem   - Ítem anidado`

**Listas ordenadas:**

- Simplemente usa números seguidos de un punto (`1.`, `2.`).

markdown

Copiar código

`1. Primer ítem 2. Segundo ítem    1. Subítem`

---

### 4. Enlaces e Imágenes

**Enlaces:** Para agregar un enlace, usa el formato `[texto](URL)`.

**Ejemplo:**

markdown

Copiar código

`Puedes visitar [OpenAI](https://openai.com) para más información.`

**Imágenes:** Usa el mismo formato que los enlaces, pero agrega un signo de exclamación al inicio.

**Ejemplo:**

markdown

Copiar código

`![Descripción de la imagen](URL_de_la_imagen)`

---

### 5. Citas y Código en Markdown

**Citas en bloque:** Para agregar citas, usa el símbolo `>` al comienzo de la línea.

**Ejemplo:**

markdown

Copiar código

`> Esto es una cita en bloque.`

**Código en línea y bloques de código:**

- Código en línea: usa una sola tilde invertida `` ` `` para resaltar el código en el texto.
- Bloque de código: usa tres tildes invertidas ` ``` `.

**Ejemplo:**

markdown

Copiar código

``Para resaltar `una palabra en código`.``

### 6. Tablas en Markdown

Markdown permite crear tablas usando `|` para dividir las columnas y `-` para definir la cabecera.

**Sintaxis básica:**

markdown

Copiar código

`| Encabezado 1 | Encabezado 2 | | ------------ | ------------ | | Fila 1, Columna 1 | Fila 1, Columna 2 | | Fila 2, Columna 1 | Fila 2, Columna 2 |`

**Ejemplo:**

markdown

Copiar código

`| Producto | Precio | | -------- | ------ | | Manzanas | $1.00  | | Naranjas | $0.50  |`
